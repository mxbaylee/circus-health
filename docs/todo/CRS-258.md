# 📚 CRS-258: Correct maintained docs that contradict PR #71 code

Status: open; PR #71 review finding. Several maintained statements describe
limits, versions or paths that the code at PR #71 head no longer has. No code
change is required; each statement must match code or be removed.

## User Story

As an [Operator](../design/personas.md#operate-and-recover),
I want the storage and import documentation to describe what the installed app
actually does,
So that I can plan capacity and recovery without trusting limits that are not
enforced.

## Plain-English User Walkthrough

1. I read the storage guide to understand how big a copy or migration can get.
2. The limits and behaviors it describes are the ones the app enforces.
3. Where the app has no limit, the guide says so instead of naming one.

## Acceptance Criteria

### Scenario: Each listed statement matches code

Given the statements listed below,
When each is checked against PR #71 head (or the head that closes this ticket),
Then it is corrected to the implemented behavior or removed,
And no new guarantee or limit is invented to make a statement true.

### Scenario: Links and anchors still resolve

Given the edited files,
When the docs link checks run,
Then every link and anchor resolves,
And items owned by other tickets (below) are left to those tickets.
