# 🔁 CRS-267: Avoid full-original hashing on each navigation page

Status: open. Sizes, production status and priority are in the [index](readme.md#crs-267).

## Scope and acceptance

As a [High-precision tracker](../design/personas.md#read-unusual-evidence), I want paging through search results in a large original to stay cheap. v2 navigation search rehashes the whole original on every page (`intake-evidence-navigation.ts:266`). Given a verified original, when later pages are read, then each page's work is bounded by the page, with changes still detected.
