# 🧹 CRS-243: Remove failed direct reconstruction targets

Status: open; direct-helper cleanup finding from PR #71. Production staged callers
remove their failed stages; the reproduced case did not activate a rejected target.

## User Story

As an [Operator](../design/personas.md#operate-and-recover),
I want an interrupted reconstruction to leave a clear retry path,
So that an unusable working copy is not mistaken for a completed recovery.

## Plain-English User Walkthrough

1. I attempt recovery into a new destination and verification refuses it.
2. The accepted source stays untouched, the failed new destination is cleaned up,
   and a corrected attempt can use that destination again.

## Acceptance Criteria

### Scenario: Final verification rejects an otherwise completed reconstruction

Given a new fixture-owned destination created by a direct asynchronous rebuild,
When the terminal proof throws after the reconstruction iterator completes,
Then the original error is preserved, database handles close, and newly owned
database/WAL/SHM files are removed,
And no target is activated and a retry can use the same new-target path.

### Scenario: Cleanup cannot erase pre-existing data

Given an existing destination or an unrelated file beside the reconstruction,
When reconstruction refuses or cleanup itself fails,
Then only artifacts owned by that attempt are eligible for removal,
And accepted sources and pre-existing targets remain unchanged.

## Evidence and Implementation Scope

`driveRecordStepsAsync` marks its iterator done before the terminal `finalProof`.
Consequently the direct `rebuildRecordDatabaseAsync` and
`rebuildContributorDatabaseAsync` helpers can leave a closed target after that
proof refuses. `rebuildProfileAsync` and startup staging wrappers have their own
stage cleanup. Cover both the direct helpers and those wrappers, without changing
the accepted-head publication or activation contract.

Owner decision, 2026-10-15: defer this narrowly bounded cleanup defect, not a
recovery-authority change or permission to activate an unverified result.
