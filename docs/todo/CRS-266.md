# 🕸️ CRS-266: Resolve HTML evidence targets without whole-intake scans

Status: open. Sizes, production status and priority are in the [index](readme.md#crs-266).

## Scope and acceptance

As a [Records assembler](../design/personas.md#read-unusual-evidence), I want HTML evidence targets resolved without scanning every intake. Supplied-target resolution does R references × N intakes `json_each` scans (`intake-evidence-collection.ts:92-133`). Given more intakes, when one HTML page resolves its targets, then work scales with its own references.
