# CRS-081: Scoped import processing after lock or logout

Status: open.

Continue only explicitly authorized import work after lock, logout or profile switch using a separately scoped authority. Ordinary Lock must still revoke general archive access. Preserve Stop/deletion, encrypted durable checkpoints, profile isolation and review before clinical acceptance.

After process loss, require authorized unlock before recovery; do not retain general profile keys merely to keep work running. Verify late responses, revocation and restart against the existing security and recovery boundaries. Background work while the current session remains authorized is already supported; this item concerns additional authority.
