# CRS-119: Move accepted records and remove confirmed aliases

Status: open.

Before acceptance, the report header's **Change** control already reassigns pending records (`ImportReviewPresentation.tsx:988` at `2ae9a0f`). After acceptance nothing moves them: the identity sheet says "Accepted records keep their existing attribution". A Self alias added by **This is me** cannot be removed, because source-known names are protected (`notes.ts:518-535,1237-1252`; `PersonNames.tsx:20-33`).

Add an audited move of accepted records to another person: a new record version under the new owner, with the earlier attribution kept in history, never an in-place rewrite. Allow removing a confirmed alias with the same audit. This matters most for a mistaken automatic Self match ([CRS-111](CRS-111.md)). Reliability review R13.

Open question: a bulk action, or only through the review workspace?
