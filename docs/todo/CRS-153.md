# 🔐 CRS-153: Complete physical passkey qualification

Status: open. Remainder of CRS-072. The actual device/HTTPS acceptance gate remains open; controlled browser tests validate the journey driver, not physical devices.

## Available automation

`npm run qualify:passkeys` runs an unmodified, headed installed Chrome or Edge on an actual trusted HTTPS origin. It refuses an installation with any existing profile, creates only a fictional profile, retains its recovery phrase in a mode-0600 external file, waits for real enrollment confirmation and three authenticator unlocks, switches from an active passkey attempt to recovery, verifies private access and locks the fictional profile. A bounded metadata receipt records only the observed progress and browser version. No virtual authenticator, credential override or TLS bypass exists in the production driver. See [physical qualification](../security/profile-encryption.md#physical-passkey-qualification).
