# 🧫 CRS-186: Reconcile accepted records and bounded cache-loss recovery

Status: open. Medium-effort, large-impact production prerequisite split from CRS-185. Proposal reconciliation and normal two-person report confirmation are implemented; this slice checks actual accepted public records and durable receipts against the literal oracle.

## Requirements

1. Add a pure read-only grader for the versioned 901-assertion large-import oracle, explicit distinct current saved-Person bindings, retained original ID and actual accepted Observation/Medication/Procedure responses. Preserve whole-oracle completeness: five observed records still leave 896 missing and cannot pass the whole oracle. Report fixed categories and fixture keys/counts without copying private record contents or identifiers.
2. Compare literal clinical fields and classifications, source linkage and exact original evidence pages, including both 149 and 150 for the split assertion. Reuse existing adaptation/page validation where sound. Grade retained `extra.import.acceptedMapping` separately from actual public projections; a correct retained mapping cannot excuse an incorrect public field. Validate public observation numeric value, comparator and date precision independently against literal expectations, preserving printed precision/signs in retained clinical evidence. Unknown or unavailable facts remain unknown/failure.
3. Check top-level accepted owner IDs against the explicit saved-Person binding (`patient` for current Self, the saved Person ID for the other person). Never infer ownership only from retained mapping, labels or names. Detect missing/extra/duplicate assertion matches, entity IDs and source evidence. Scope all records to the intended fictional fixture and original; unrelated records cannot fill expected gaps.
4. Capture real current reviewed selections before acceptance. Reconcile receipts against those selections and fetched accepted entities: intake/proposal, selected record and candidate/version, kind, entity ID and outcome. Detect missing/additional receipt entries, duplicate entities, count mismatches, wrong-kind entities and absent accepted records. Do not treat an ID in a receipt as proof that its current clinical projection is correct.
5. Extend the existing independently authored five-record, two-person HTTP fixture through actual exact-version atomic acceptance. Replay the identical request and retrieve its operation receipt; require identical receipts and unchanged accepted counts. Fetch real public details and owner-filtered lists. Verify original bytes/hash and saved demographics remain unchanged. Only this fresh temporary fictional profile may receive accepted writes.
6. Exercise lock, removal of only the test-owned encrypted cache using the established containment/symlink protections, recovery-kit unlock and confirmed rebuild. Re-fetch public accepted records, ownership/counts, original bytes and operation receipts; replay the original acceptance request and regrade. Accepted versions, retained originals and medical history remain recovery authority; never delete source evidence or any owner/demo data. This bounded test does not qualify process/container recreation or a full-size run.
7. Add full-oracle synthetic grading and adversarial cases for swapped owners, corrupted public numeric projections, missing split evidence, mismatched receipt versions/entities, duplicate/extra records, missing records and retained mappings masking wrong public fields. The actual independent five-record API acceptance/rebuild path is required; synthetic copies alone are insufficient.
8. Keep work proportional to supplied oracle/records/receipts. No storage schema/migration, general pipeline harness, full 900-page processing, paid/live provider or owner demo access is included. Reuse the current contracts without adding old-schema support.
9. Document the actual APIs, authority, projection distinctions and limits. Run focused local tests, formatting/type checks, full PR CI and independent review. Delete this ticket/index entry on completion and preserve every unfinished CRS-185 requirement in a scoped remainder.
