# 📇 CRS-268: Make People index preparation incremental

Status: open. Sizes, production status and priority are in the [index](readme.md#crs-268).

## Scope and acceptance

As a [Caregiver](../design/personas.md#file-family-records), I want People review to stay fast as imports grow. The People index caches the last proposal and adopts derived draft/disposition indexes. Switching proposal sources still parses and hashes the full proposal, pointer lookup uses a linear entry search, and uncovered mutations can rebuild the index. Given one changed proposal, when the index updates, then only that proposal's entries are rewritten.
