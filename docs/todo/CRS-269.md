# 🧳 CRS-269: Count and reduce repeated legacy startup and ownership reads

Status: open. Sizes, production status and priority are in the [index](readme.md#crs-269).

## Scope and acceptance

As an [Operator](../design/personas.md#operate-and-recover), I want legacy startup and ownership preview to cost what they read. The historical estimate of about 10×N startup reads needs fresh counted measurement; current legacy portable startup still projects twice (`portable.ts` ~3402-3855), and legacy `previewOwnershipNames` does owners × candidates ledger passes. Given a legacy profile, when it starts or previews ownership, then each source is read once.
