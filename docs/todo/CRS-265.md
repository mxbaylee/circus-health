# 🐢 CRS-265: Bound accepted-history lookup during review

Status: open. Sizes, production status and priority are in the [index](readme.md#crs-265).

## Scope and acceptance

As a [Records assembler](../design/personas.md#file-and-review), I want review pages to open promptly on a long history. `latestAcceptedRecordWork` is O(entries × decisions) per interactive review preparation (`intake-review-collection.ts:1769`, `clinical-import.ts:822,926`). Given more accepted history, when a review is prepared, then work scales with the records reviewed, not the whole history.
