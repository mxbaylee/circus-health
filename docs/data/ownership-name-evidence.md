A choice posts one association key/outcome and returns a fresh approval token; it does not put all supporting targets or choices in the request body. Page cursors do not authorize missing evidence: the complete plan is checked before any page can be served or any choice saved.

Each database connection retains one selected plan and allows one preparation at a time. Lock/close cleanup closes its scratch and invalidates pending preparation epochs.
